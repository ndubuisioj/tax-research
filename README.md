# tax-research

A browser-based workspace for U.S. tax research and practice.

## Run

Open `taxresearch.html` in a browser, or select **Launch Fieldwork Tax** in VS Code's Run and Debug panel. The app has no build step or package dependencies.

Research links point to IRS.gov publications and guidance. They are research aids, not statutory text; practice scenarios are educational and should be checked against current authority before use in client work.
